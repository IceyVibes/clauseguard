Problem

Registration takes seconds. Reading the agreement takes minutes.

Digital services make joining easy, but agreements may contain recurring payments, information-sharing permissions, dispute restrictions and account-control provisions that users may not notice before accepting.

Idea

ClauseGuard provides an attention layer before acceptance. It identifies individual clauses that resemble patterns in the student-created training dataset and shows which categories may deserve review.

Student ML journey

Create synthetic data → Label clauses → Generate MiniLM embeddings → Train Logistic Regression → Measure performance → Save model → Serve through FastAPI → Integrate browser extension

Why the demo is interesting

  • Students create and label training data.
  • Students train and evaluate their own classifier.
  • No paid AI inference API.
  • Inference can run locally.
  • Browser extension works across multiple fictional websites.
  • Findings point to original displayed clauses.
  • Results include measured model confidence.
  • Form data is not sent for analysis.

Responsible AI

  • Synthetic training data
  • No legal conclusions
  • Confidence is model confidence, not legal certainty
  • False positives are possible
  • False negatives are possible
  • Human review remains necessary
  • Local processing
  • No registration-form data is analyzed
